# designer, in this project

The role itself is shared and lives outside this repository, at `~/.claude/agents/designer.md`.
If you have cloned this project that file will not be there, and nothing here depends
on it: what follows is a description of THIS repository's commands, paths and hazards,
which is useful on its own. Where both exist, this file wins.

Launch with `npm run check`, which builds before it checks, then open the built output in a browser. The screen is the browser window; judge it at phone width as well as desktop.

This is the page somebody reads before deciding to install. Judge it as a stranger who has never heard of the product, not as somebody who knows what it does.

There is no separate product document.
