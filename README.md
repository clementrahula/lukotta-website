# Lukotta website

The website for **Lukotta**, an application that opens BitLocker, Linux and
virtual machine disks on macOS. One page, in thirty-seven languages.

- **[lukotta.com](https://lukotta.com)** — the site this repository builds
- **[The application](https://github.com/clementrahula/lukotta)** — source, releases and issues
- **[Licence](LICENSE.txt)** — GPL-3.0-or-later
- **[Third-party notices](THIRD_PARTY_NOTICES.md)** — the two typefaces the site carries
- **[Trademarks](https://github.com/clementrahula/lukotta/blob/main/TRADEMARKS.txt)** — the Lukotta name and logo are not covered by the licence

```bash
npm start        # build and serve at localhost:4321
npm run check    # build, then check the result
```

Everything the page says lives in `content/`. [AGENTS.md](AGENTS.md) has the rest.
